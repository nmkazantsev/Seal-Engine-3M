# Архитектура движка Seal Engine 3M

## Общая архитектура

Проект представляет собой кроссплатформенный движок с разделением на модули и мосты для различных платформ.

### Основные модули:

+ **core** - Ядро движка
    + Основные классы и интерфейсы
    + Логика приложения
    + Платформо-независимые компоненты

+ **desktop** - Десктопная реализация
    + Реализация графики через Skija
    + Реализация аудио через JavaZoom
    + Desktop-specific мосты

+ **android** - Android реализация
    + Реализация через Android SDK
    + Использование MediaPlayer и SoundPool
    + Android-specific мосты

### Мосты и интерфейсы:

+ **PlatformBridge** - Мост между ядром и платформой
    + Позволяет ядру взаимодействовать с платформой
    + Обеспечивает абстракцию от конкретной реализации

+ **AudioPlayer** - Интерфейс для работы с аудио
    + Общий интерфейс для воспроизведения музыки и звуков
    + Реализации для desktop и android

+ **AssetManager** - Управление ресурсами
    + Загрузка файлов из ресурсов
    + Обеспечивает доступ к файлам на разных платформах

## Startup Sequence (Desktop)

1. **Инициализация движка**
    + Создается экземпляр `CoreRenderer`
    + Инициализируются основные компоненты

2. **Создание моста**
    + Создается `DesktopBridge` (реализация `PlatformBridge`)
    + Инициализируется `AssetManager` для desktop

3. **Инициализация графики**
    + Создается `PImageDesktop` для рендеринга
    + Инициализируется `Surface` и `Canvas` через Skija

4. **Инициализация аудио**
    + Создается `AudioPLayerDesktop`
    + Инициализируется `SimpleMp3Player` через JavaZoom

5. **Запуск игрового цикла**
    + Запускается основной цикл обновления и рендеринга
    + Используются реализации `AbstractImage` и `AudioPlayer`

6. **Загрузка ресурсов**
    + Через `AssetManager` загружаются необходимые файлы
    + Подготавливаются к использованию

7. **Запуск приложения**
    + Инициализируются основные компоненты
    + Запускается основной поток выполнения

## Архитектурные особенности

+ **Мостовая архитектура**: Ядро не зависит от конкретной платформы
+ **Интерфейсы**: Используются для абстрагирования платформенных особенностей
+ **Разделение ответственности**: Каждый модуль отвечает за свою область
+ **Кроссплатформенность**: Один код, разные реализации под платформы
